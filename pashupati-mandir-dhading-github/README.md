# पशुपति मन्दिर धादिङ — GitHub वेबसाइट प्याकेज

यो ZIP प्याकेजमा तपाईंको वेबसाइटको पूरा कोड, मुख्य मन्दिर फोटो, भजन अडियो र व्यवस्थित फोल्डर संरचना तयार गरिएको छ।

## फोल्डर संरचना (GitHub मा जस्ताको तस्तै अपलोड गर्नुहोस्)
- `index.html` — मुख्य वेबसाइट फाइल
- `images/`
  - `hero-main.png` — **अगाडि डिस्प्ले (Hero र परिचय) मा सधैं राखिरहने मुख्य फोटो**
  - `gallery-1.png` देखि `gallery-12.png` — **ग्यालरीमा परिवर्तन/थपिरहने फोटोहरू** (`.png`, `.jpg`, `.jpeg`, `.webp` समर्थन गर्छ)
- `audio/`
  - `bhajan/` — **बिहान–बेलुका बज्ने भजनहरू** (`bhajan-1.mp3`, `bhajan-2.mp3` ... `bhajan-10.mp3`)
  - `aarti/` — **आरती भजनहरू** (`aarti-1.mp3`, `aarti-2.mp3` ... `aarti-10.mp3`)

## १. अगाडि रहने फोटो र चेन्ज गर्ने फोटो कसरी राख्ने?
1. अगाडि डिस्प्लेमा सधैं राखिरहने फोटोलाई `images/hero-main.png` (वा `.jpg`) नाम दिएर राख्नुहोस्।
2. ग्यालरीमा चेन्ज गरिरहने वा नयाँ थप्ने फोटोहरूलाई `images/gallery-1.png`, `images/gallery-2.png` ... `images/gallery-12.png` नाम दिएर `images/` फोल्डरमा अपलोड गर्नुहोस्।

## २. बिहान–बेलुका बज्ने भजन र आरती भजन कहाँ हाल्ने?
- **बिहान–बेलुका बज्ने भजन:** `audio/bhajan/` फोल्डरभित्र `bhajan-1.mp3`, `bhajan-2.mp3` आदि नाम दिएर राख्नुहोस्।
- **आरती भजन:** `audio/aarti/` फोल्डरभित्र `aarti-1.mp3`, `aarti-2.mp3` आदि नाम दिएर राख्नुहोस्।

## ३. YouTube मा प्रोग्राम हुँदा वेबसाइटमा कसरी लाइभ गर्ने?
1. YouTube मा Live सुरु भएपछि त्यसको लिंक (जस्तै `https://youtu.be/VIDEO_ID` वा `https://www.youtube.com/live/VIDEO_ID`) कपी गर्नुहोस्।
2. GitHub मा `index.html` खोलेर Pencil (Edit) आइकन थिच्नुहोस्।
3. `const YOUTUBE_LIVE_INPUT = "";` खोजेर खाली `""` भित्र आफ्नो लिंक राख्नुहोस्:
   ```js
   const YOUTUBE_LIVE_INPUT = "https://youtu.be/VIDEO_ID";
   ```
4. **Commit changes** गर्नुहोस् — वेबसाइटमा स्वतः 🔴 LIVE भिडियो देखिनेछ।
5. प्रोग्राम सकिएपछि फेरि `""` खाली राख्नुहोस्।
